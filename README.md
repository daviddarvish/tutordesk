# TutorDesk

מערכת לניהול שיעורים פרטיים: אפליקציה למק ולאייפון שעובדת ישירות מול גיליון Google Sheets, עם התראות לטלפון דרך ntfy.

- **הגיליון** הוא מקור האמת. אפשר להמשיך לערוך בו ידנית.
- **המנוע** (`apps-script/Code.gs`) רץ בתוך הגיליון: לשוניות מסודרות, העברת נתונים, API מוגן במפתח, בדיקות מתוזמנות.
- **האפליקציה** (`app/`) מותקנת מהדפדפן למסך הבית באייפון ול-Dock במק. היא מכילה רק קוד. הנתונים לא עוברים דרך GitHub.

## התקנה

### 1. המנוע בגיליון
1. בגיליון "שיעורים פרטיים": תוספים (Extensions) ← Apps Script.
2. מחק את התוכן של `Code.gs` והדבק את הקובץ `apps-script/Code.gs`. שמור.
3. רענן את הגיליון. יופיע תפריט **🎓 TutorDesk**.
4. TutorDesk ← **1. התקנה**. גוגל תבקש הרשאות: "Advanced" ← "Go to … (unsafe)" ← Allow. זה תקין לסקריפט פרטי שלך.
5. TutorDesk ← **2. העברת נתונים**. קרא את הדוח, במיוחד יתרות הפתיחה.
6. בלשונית **תלמידים**: ודא "ימים", "שעה" ו"מחיר לשיעור" אצל הקבועים. מהם נבנה לוח היום.

### 2. פרסום ה-API
1. ב-Apps Script: Deploy ← New deployment ← סוג **Web app**.
2. Execute as: **Me**. Who has access: **Anyone**.
3. Deploy, והעתק את כתובת ה-Web App (מסתיימת ב-`/exec`).

הגישה "Anyone" נדרשת כדי שהאפליקציה תוכל לפנות לסקריפט. כל בקשה בלי המפתח הסודי נדחית.

### 3. חיבור האפליקציה
1. בגיליון: TutorDesk ← **חיבור האפליקציה**. הדבק את כתובת ה-`/exec`.
2. **אייפון:** סרוק את ה-QR במצלמה ← נפתח Safari ← שיתוף ← הוסף למסך הבית.
3. **מק:** העתק את הקישור, פתח ב-Safari ← קובץ ← הוסף ל-Dock.
4. אם האפליקציה המותקנת מבקשת חיבור, הדבק את הקישור פעם אחת בהגדרות.

### 4. התראות
1. התקן **ntfy** מה-App Store.
2. לחץ **+** והירשם לנושא שמופיע בחלון החיבור ובהגדרות האפליקציה.
3. בגיליון: TutorDesk ← **שליחת התראת בדיקה**.

## מה נשלח ומתי
| התראה | מתי | מה |
|---|---|---|
| סיכום בוקר | שעת הבוקר בהגדרות (ברירת מחדל 7) | שיעורי היום, פולו-אפים, חובות מעל הסף, קבועים שנעלמו |
| בדיקת ערב | שעת הערב (ברירת מחדל 20) | שיעורים שלא סומנו, ושיעורי מחר עם כפתור תזכורת בוואטסאפ |
| סיכום שבועי | יום ראשון בבוקר | שיעורים, שעות, חיוב מול גבייה, יתרות, קבועים מול יעד |

כשאין מה לדווח, לא נשלחת התראה. ההגדרות נערכות בלשונית **הגדרות** בגיליון ונכנסות לתוקף מיד.

## עדכון קוד
שינוי ב-`Code.gs` דורש גרסה חדשה: Deploy ← Manage deployments ← עריכה ← Version: New version. הכתובת נשארת אותה כתובת.

## בדיקות
`test/` מריץ את `Code.gs` מול הדמיה של שירותי גוגל עם נתונים בדויים:

```
node test/run-backend-test.js      # בדיקות המנוע
node test/seed.js                  # יוצר את app/demo.json
node test/mock-server.js 8765      # האפליקציה + המנוע מקומית
python3 test/screens.py out/       # צילומי אייפון ומק + תרחישי שימוש
```
